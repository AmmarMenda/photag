# photag

A lightweight, high-performance desktop application built in **C** for identifying and organizing image collections. The app scans a directory, uses a neural network to detect objects, and allows you to filter or sort your library based on those generated tags.

---

## Features

* **Neural Network Inference:** Uses the [Darknet](https://pjreddie.com/darknet/) framework to perform real-time object detection.
* **Automated Tagging:** Identifies objects (e.g., "dog", "car", "person") within images and assigns them as searchable metadata.

---

* **Graphics:** OpenGL / GLFW
* **Image Loading:** stb_image
